The read surface

Reached by long-press on home. Default filter is "All" — the full unified timeline. Tap any chip to filter to a single type. The count beside each chip is a passive insight: "31 restaurants this year" tells you something just by being there.

Entry types render differently

Each type gets its own row layout, but they share the same left rail (day number + day-of-week). Day log shows prose + extracted tags. Restaurant shows name as headline + structured meta line + italicized quoted note. Media shows title + format pill + italicized note. Thoughts render entirely in serif italic — a different visual register from the structured entries, signaling "this is reflection, not record."

Three Friday entries from one write

Look at May 15 — three entries stacked. The Raoul's writeup we drew in the + flow produced a primary Restaurant entry, an attached Day Log entry, and an attached Media entry for Conclave. They all share the same date but show separately in the timeline, each in their own native layout. Filter to "Restaurants" and you'd only see the Raoul's row.

What's missing here that the spec needs

Search (icon present, behavior TBD — probably searches across prose, place names, titles, and tags). Tap-to-drill on an entity (tap "Mandy" in tags → see all entries mentioning Mandy). Month divider becomes scroll-sticky when you scroll past it. Empty states per filter. These all belong in the spec doc, not in this mock.
